# Серверный чек-лист регрессий

Ручной клиентский прогон и контролируемый crash/restart сценарий: **NOT RUN**. JUnit и `forge selftest` не заменяют эти проверки. Для ручного прогона используйте отдельный Purpur/Paper 26.2 и Java 25 с тестовыми игроками и мирами.

Автоматический серверный `forge selftest` этого PR был выполнен на изолированном Purpur 26.2 (26.2-2633-HEAD@3f5d9c0), Java 25.0.4 Corretto; результат — **PASS**. Он создал и восстановил один временный воздушный блок в тестовом мире.

## Forge smithing

- [ ] Подписанные кованые алмазные меч, кирка, топор, лопата, мотыга, шлем, нагрудник, поножи и ботинки не дают незеритовый результат.
- [ ] Повторить для обычного клика, Shift+click, числовых клавиш хотбара и повторных кликов; предмет, шаблон и слиток сохраняют количество.
- [ ] Проверить отмену при смене входов и закрытии/повторном открытии интерфейса; нет ghost-result.
- [ ] Повреждённый Forge PDC/signature не легализуется smithing.
- [ ] Обычные, не принадлежащие ForgeSystem алмазные предметы по-прежнему улучшаются по ванильному рецепту.
- [ ] У кованой вещи остаются UUID, кузнец, качество, имя и зачарования после отменённой попытки.

## Закалка и вода

- [ ] С уровнями котла 3, 2 и 1 каждая успешная закалка уменьшает уровень ровно на один; уровень 1 превращает котёл в пустой.
- [ ] Обычная вода, река/океан и пустой котёл не меняют предмет или блок.
- [ ] Проверить железо, золото и медь; броня заканчивает путь в `FINISHED`, инструменты и меч переходят в `QUENCHED_PART`.
- [ ] Повторный клик с уже закалённым предметом не расходует воду; повреждённая подпись и отсутствие `forgesystem.use` не меняют мир или инвентарь.
- [ ] Два быстрых клика одним игроком и два игрока у одного котла не дублируют переход или расход.
- [ ] Проверить котёл на чужой защищённой территории; отменённое сторонним плагином событие не меняет предмет и воду.
- [ ] На тестовой копии прервать сервер в каждом окне операции (после записи журнала, после сохранения игрока, после изменения/сохранения блока); запустить снова и сверить UUID, состояние предмета и уровень котла.
- [ ] Проверить отказ записи `state.yml` и невозможность сохранить мир; операция должна закрыться fail-closed, без повторного списания.

## Общий игровой цикл и инвентарь

- [ ] С двумя игроками пройти создание → нагрев → ковку → закалку → рукоять → алмазное улучшение.
- [ ] Проверить разные типы/состояния наковальни, оба хвата, offhand и защиту территории.
- [ ] Проверить `Shift`, drag, double-click, `1–9`, `F`, `Q`, creative middle-click, смерть, disconnect, закрытие GUI и полный инвентарь.
- [ ] Проверить штатную остановку плагина и сервера, восстановление после входа и повторный `/forge claim`; предметы не пропали и не удвоились.

Записать точные версии сервера/Java, сборку плагина, шаги, ожидаемое и фактическое состояние и журналы. Контролируемое убийство процесса выполнять исключительно в этой тестовой установке.
