# Происхождение материалов

Проект ForgeSystem предназначен для сервера ServerMine. Отдельная открытая лицензия для собственного кода пока не выбрана владельцем; не следует считать размещение репозитория выдачей такой лицензии.

Текстуры в `tools/vanilla-items` извлечены из официального клиента Minecraft Java 26.2. Они принадлежат Mojang/Microsoft и используются как исходники для предпросмотра и определения геометрии. Игровые модели ссылаются на текстуры установленного клиента. Ссылки на источник и контрольная сумма клиента приведены в [описании текстур](tools/vanilla-items/README.md).

`tools/forge-art.png` и `tools/hammer-16.png` созданы с помощью image_gen и подготовлены для проекта. Описание запросов находится в `tools/IMAGE_PROMPT.md` и `tools/hammer-generation.md`.

Gradle Wrapper содержит собственные уведомления Gradle об авторских правах и лицензии. Зависимости Paper API, Adventure, JUnit и другие библиотеки загружаются при сборке и имеют собственные лицензии.

Проект не является официальным продуктом Minecraft и не связан с Mojang/Microsoft.
